## Quality & Code Review Philosophy

I don't treat testing and review as a formality — they're where most real bugs get caught before a user ever sees them.

<table width="100%">
<tr>
<td width="50%" valign="top">

**Testing**
- Write JUnit tests alongside the service logic, not after the feature is "done"
- Prioritize testing business logic and edge cases over trivial getters/setters
- Treat a failing test in CI as a blocker, not a suggestion

</td>
<td width="50%" valign="top">

**Code Review**
- Review my own diff before requesting review — catches obvious issues early
- Give specific, actionable feedback rather than vague comments
- Treat review feedback as a chance to learn a teammate's perspective, not as criticism

</td>
</tr>
</table>

###  AI Job Application Assistant

An AI-powered mobile application that automates recruiter email generation based on resume and job details.

**The problem:** Job seekers spend hours writing personalized recruiter emails and manually checking whether their resume matches a job description.

**What it does:**
- AI-generated recruiter emails tailored to resume & job details, powered by **Google Gemini API**
- Resume ATS Analysis using **PDFBox** — generates ATS score, skill gap analysis & improvement suggestions
- Bulk email automation with **Resend SMTP**
- Secure **JWT-based authentication** on all APIs
- **PostgreSQL** database integrated with **Railway** for cloud deployment

**Architecture:** React Native mobile client → Spring Boot REST API → PostgreSQL, with the Gemini API called server-side for resume analysis and email generation, and Resend SMTP handling outbound mail.

**What I learned:** integrating a third-party LLM API into a production request flow, handling PDF parsing reliably across different resume formats, and structuring JWT auth for a mobile client.
